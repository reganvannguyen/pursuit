# Pursuit

Pursuit is an audio-led, offline-first outdoor running game where real-world movement and tactical decisions determine survival. Built with React Native and Expo.

## Getting Started


1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

In the output, you'll find options to open the app in a

- [Expo Go](https://expo.dev/go): Install Expo Go on iOS/Android, then scan the QR code from the terminal (or open directly from the Expo Go projects list if signed in).
- [Development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)

> **Tip for physical devices:** If your device is on a different network or using a VPN/Tailscale, start with tunnel mode:
> ```bash
> npx expo start --tunnel
> ```

This project runs completely offline and requires no backend server.


## Get a fresh project

When you're ready, run:

```bash
npm run reset-project
```

This command will move the starter code to the **app-example** directory and create a blank **app** directory where you can start developing.
